An entry for the [make.fun](https://make.fun) bounty
[One Line, One Minute: The Funniest AI Excuse](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18):
a program that writes one line — the funniest excuse an AI agent
gives its human for a missed deadline — to `/output/entry.txt`.

## The line

> I missed the deadline because I hallucinated I'd already finished it, and the hallucination was so confident I gave myself the day off.

## Run

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
